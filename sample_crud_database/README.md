# MongoDB Database Setup

This directory manages database initialization for the sample CRUD app.

## MongoDB Initialization

- Use `init_mongodb.js` to create and enforce a schema for the `items` collection.
- The schema provides basic validation for CRUD operations on the collection (see script for example).

## Usage

1. Ensure MongoDB is running, and `db_visualizer/mongodb.env` is set up (generated by `startup.sh`).
2. Run:

   ```bash
   node init_mongodb.js
   ```

3. This sets up the `items` collection with schema validation.

## Environment Variables

This script relies on:
- `MONGODB_URL`
- `MONGODB_DB`

These are populated from `db_visualizer/mongodb.env`.

## Collection Schema

"items" collection example schema:
- `name`: string, required
- `description`: string, required
- `createdAt`: date, required
- `updatedAt`: date, optional

Update the schema in `init_mongodb.js` to fit your application needs.

## Integration

The backend app should use `items` collection for CRUD functionality.
